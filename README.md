# SPEED!

Speed! is a simple top down racing game.

## How to set up

1. Ensure you have Python 3 available (already default on recent versions of Mac OS)
2. Checkout the code: `git clone https://github.com/EdwardJ123/Driving-Game.git`
3. `cd Driving-Game`
4. Install Pygame: `pip install pygame`
5. Start the game: `python game.py`

## How to play

Use the arrow keys to move the car around the track and follow the track through the checkpoints and the finish line to complete a lap. Complete three laps to finish the race. The car will go fastest on the track and slowest on the yellow sand. To pass through the checkpoint and the finish line you must go over the lines as going near them does not count.
